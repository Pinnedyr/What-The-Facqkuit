Questions

Quick answers.

Do I need an API key?

No. The chatbot uses Puter, which provides the AI for free. You only need a free Puter account, and the app helps you create one the first time you open it.

Where are my chats saved?

In your browser’s local storage on the device you use. Clearing your browser data removes them, so export anything important first using /export.

Can I use it offline?

You can open the file offline, but the AI needs an internet connection to answer.

Is there a usage limit?

Usage is covered by your Puter account, which has its own allowance. If you reach it, the app tells you, and you can try again later or pick a lighter model.

Does voice input work everywhere?

Dictation records audio and transcribes it on your device. The first use downloads a speech model once, and it is cached afterwards.

The download didn’t start. What now?

Right-click the download button and choose “Save link as”. Make sure Ai chatbot.html sits in the same folder as this page.
